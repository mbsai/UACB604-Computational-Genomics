# UACB-604 · Computational Genomics

Interactive lecture slides and notebooks for UACB-604 (B.Sc. AI & Computational Biology, Semester VI).

### 👉 Course website: https://mbsai.github.io/UACB604-Computational-Genomics/

**How to use**
- Lectures are numbered by unit: `1.2` = Unit 1, Lecture 2. Open them from the course website above. In the slides use the arrow keys to move, `F` for fullscreen, `Esc` for the slide overview.
- Slides marked **interactive** or **game** respond to you: type, drag sliders and click.
- Each lecture has a Google Colab notebook (in `unitNN/notebooks/`). The **Notebook** buttons on the website open it directly in Colab. For R notebooks choose **Runtime → Change runtime type → R**.
- **In class** the slides run in live mode from the teacher's laptop (`classroom/server.py`): join with your name, and your screen follows the lecture.

What the game showed biology

Genome size does not track complexity

Human and mouse have about the same number of protein-coding genes as a 1 mm worm.

Bread wheat has 5× our genome and 5× our genes: it carries three ancestral genomes (hexaploid).

Most of a large genome is repeats and non-coding DNA. This is the C-value paradox.

Maths consequence: genome length \(n\) is a poor predictor of gene count \(g\). We will need models, not proportions.

Formal definition maths

A genome is a string

Alphabet \(\Sigma = \{\texttt{A},\texttt{C},\texttt{G},\texttt{T}\}\)

A sequence of length \(n\): \(s = s_1 s_2 \dots s_n,\; s_i \in \Sigma\)

DNA is double-stranded. The partner strand is the reverse complement: $$\overline{s} = c(s_n)\,c(s_{n-1})\cdots c(s_1)$$ with \(c: \texttt{A}\leftrightarrow\texttt{T},\ \texttt{C}\leftrightarrow\texttt{G}\).

Read the bottom strand 5′→3′ (right to left) to get \(\overline{s}\).

Every algorithm we write must decide: one strand or both?

Biology adds structure the string hides: chromosomes (several strings), circular genomes (bacteria, mitochondria: the string has no ends), and two copies of each chromosome in humans (diploid).
4 min. Ask: is reverse complement an involution? (yes, applying it twice gives back s). How many distinct strings of length 10? 4^10 ≈ 1 million.

How much information? maths

Bits in a genome

4 symbols → \(\log_2 4 = 2\) bits per base, if all are equally likely.

Human: \(3.1\times10^9 \times 2\ \text{bits} \approx 775\ \text{MB}\).
The usual FASTA text file is ~3 GB. Why 4× bigger?

If bases are not equally likely, use Shannon entropy: $$H = -\sum_{x\in\Sigma} p_x \log_2 p_x \;\le\; 2$$

Think, then discuss (1 min)

Two people differ at roughly 1 base in 1,000. How would you store your genome if everyone already has the reference human genome?

Answer: store only the differences (variants). This is exactly what a VCF file does (Unit 2). Compression = knowing what to expect.
4 min. FASTA uses 1 byte (8 bits) per character plus line breaks → 4× the 2-bit minimum. Differences: ~0.1% of 3.1 Gb ≈ 3–4 million variants.
A rule and a mystery maths biology

Chargaff's rules

First rule (explained)

In double-stranded DNA: \(\#A = \#T\) and \(\#G = \#C\).

Every A pairs with a T. So one number, the GC content \(g\), fixes the whole composition: $$p_A = p_T = \tfrac{1-g}{2},\quad p_G = p_C = \tfrac{g}{2}$$

Second rule (still debated)

Even within one strand, \(\#A \approx \#T\) and \(\#G \approx \#C\) for long sequences, in almost every genome checked.

Nothing in base pairing forces this. Proposed explanations involve inversions and transposons, but there is no agreed proof. A genuine open question for mathematicians.

Check it in the sequence lab: a random string satisfies it by construction. A real bacterial chromosome does too, which is the surprise.

3 min. GC content varies a lot between species: ~25% to ~75% in bacteria. It is a species signature, used later in metagenomic binning (Unit 12).

Expected k-mer counts

A k-mer is a substring of length \(k\). In a random genome of length \(n\), a given k-mer is expected $$E[\text{count}] \approx \frac{n}{4^{k}}$$ times (one strand).

Finding genes as signal in noise interactive maths

How long is a stretch without a stop codon?

Genes are read in codons (3 bases). 3 of the 64 codons are stop (TAA, TAG, TGA). In random DNA each codon is a stop with probability \(p = 3/64\).

Codons before the first stop, \(L\), is geometric: $$P(L=k) = (1-p)^k\,p,\qquad E[L] = \tfrac{1-p}{p} \approx 20.3$$

Wrap-up

Today in one slide

  • A genome is a string over {A,C,G,T}, but with two strands, several chromosomes and sometimes no ends.
  • Genome size ≠ gene count (C-value paradox).
  • About 2 bits per base; storing differences is far cheaper.
  • In a random genome of length \(n\), words of length \(k \gtrsim \log_4 n\) are unique.
  • Long open reading frames are improbable by chance: a statistical signal of genes.

Read an accession game maths

What kind of record is this?

Card 1 of · score 0

Accessions follow patterns, which a computer can match with regular expressions:

N[CGTWZ]_\d+  RefSeq DNA
[NX]M_\d+    RefSeq mRNA
[NX]P_\d+    RefSeq protein
ENS[GTP]\d{11} Ensembl gene/transcript/protein
[OPQ]\d[A-Z0-9]{3}\d  UniProt (one form)

.version at the end (e.g. NM_000546.6) changes when the sequence changes. Cite the version.

5 min. N = curated (known), X = predicted (model). Regular expressions are formal languages: maths students may know them from automata theory.

The same gene, three addresses

The human reference genome is updated. Coordinates are only meaningful with the assembly name.

AssemblyYearTP53 (1-based, NCBI)

GRCh37 → GRCh38 shifted TP53 by 96,682 bp. A variant at chr17:7,577,120 is inside TP53 on GRCh37 but nowhere near it on GRCh38.

“Lift-over” tools convert coordinates between assemblies. Maths view: a piecewise translation map, mostly \(x \mapsto x + c_i\) on blocks, undefined where sequence was added or removed.

T2T-CHM13 is the first gap-free (“telomere-to-telomere”) human genome. Values retrieved from NCBI Gene, November 2026.

Real trap: NCBI's gene web page says TP53 starts at 7,668,421; NCBI's own API returns 7,668,420. Same database, two conventions. You'll meet it in the notebook.

5 min. Half-open intervals are what mathematicians and programmers like: lengths are e − s, and adjacent intervals [a,b) [b,c) share no base and leave no gap.
Relations, not functions maths

Databases disagree, and mappings branch

Where is TP53? (both GRCh38, 1-based)

NCBI   : 7,668,421 – 7,687,490
Ensembl: 7,661,779 – 7,687,546

Each defines a gene as the span of its own transcripts. Ensembl lists 40 transcripts for TP53; one extends 6.6 kb further.

KEGG maps hsa:7157 to three UniProt entries (one reviewed, two unreviewed). An ID mapping is a relation; it is a function only if each key maps to one value. Check before you join tables, or rows multiply.

4 min. Joining a 20,000-row table through a one-to-many mapping can silently produce 60,000 rows.

From clicks to code

A URL can be a function call

GET https://rest.ensembl.org/lookup/symbol/homo_sapiens/TP53
→ {"id": "ENSG00000141510", "seq_region_name": "17", "start": 7661779, "end": 7687546, "strand": -1, "assembly_name": "GRCh38", …}

GET https://rest.kegg.jp/link/pathway/hsa:7157
→ hsa:7157  path:hsa01522
   hsa:7157  path:hsa01524  …

GET https://rest.uniprot.org/uniprotkb/P04637?format=fasta
  • Input (the gene) goes in the URL; output comes back as data (JSON, tables, FASTA).
  • A script that queries 500 genes is reproducible; 500 browser clicks are not.
  • Be polite: a few requests per second at most (NCBI asks for ≤ 3 per second without a key).
2 min. The notebook does exactly this for five genes.

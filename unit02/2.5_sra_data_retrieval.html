How raw data are organised biology

From a study to its FASTQ files

  • Journals require raw reads to be deposited, so published data are (usually) public.
  • Metadata (who, what, how) lives at each level; the data (reads) belong to runs.
  • Search by BioProject to find every run of a study; download by run.
  • NCBI's SRA Run Selector and ENA's project pages list runs with links.

Planning interactive maths

How long will it take?

data size
network speed
download time

File sizes are in bytes (B); network speeds in bits per second (bit/s). 1 byte = 8 bits.

$$t = \frac{\text{size (bytes)} \times 8}{\text{speed (bit/s)}}$$

The whole PRJNA229998 project is about 50 GB (16 runs; you'll total it in the notebook).

Real transfers are slower than the line speed (shared networks, server limits). Plan for ×2.

4 min. Watch the classic mistake: MB vs Mb (megabytes vs megabits): a factor of 8.
Did it arrive intact? interactive maths

Checksums: a fingerprint of a file

type anything:
MD5 fingerprint (128 bits, 32 hex characters)

Change one letter, even GATTACA → GATTACC, and the whole fingerprint changes.

Real file (SRR41113426_1.fastq.gz):

ENA says   6ca863749adaa842b3316d37e93934ed
1 bit flipped f5cf1a1a45f99f7df745af0d0dc0f3ec

  • A hash function turns any amount of data into a short, fixed-size fingerprint.
  • Same input → always the same fingerprint; tiny change → completely different one.
  • Databases publish the MD5 of each file; after downloading, compute yours (md5sum file) and compare.
  • \(2^{128} \approx 3.4\times10^{38}\) possible fingerprints: an accidental match is (practically) impossible: the birthday problem from 2.3 again.

MD5 is fine for catching accidental corruption, but not for security against deliberate tampering (use SHA-256 there).

4 min. The widget computes real MD5 in the browser. md5("GATTACA") can be checked in the notebook with hashlib.
The graphical way practice

FTP with FileZilla

  1. Install FileZilla (free).
  2. Host ftp.sra.ebi.ac.uk, user anonymous, no password, port 21; click Quickconnect.
  3. Navigate the remote side to the run's folder (from ENA's fastq_ftp field).
  4. Drag files to your computer.

Good for browsing and occasional downloads. For many files, a script (wget loop) is faster and records exactly what you did.

3 min. If the campus blocks FTP (port 21), use the https:// links instead.
Good habits practice

Treat raw data as read-only

Do

  • Keep a README: accessions, dates, download commands
  • Save the published checksums and verify them
  • Download with a script, so it can be repeated
  • Keep raw files untouched, in their own folder (make them read-only)

Don't

  • Rename or edit raw FASTQ files by hand
  • Unzip huge FASTQ files without need: most tools read .gz directly
  • Mix assemblies or versions without writing down which
  • Trust a download you haven't checked
